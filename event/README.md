# event/

The definition of the event itself: why, for whom, in what shape, and what happens after.

| File | Purpose |
|---|---|
| `concept.md` | Framing, working titles, goals, audience justification, intended outcomes |
| `format-options.md` | Size and format alternatives with trade-offs (50 vs 100, talks vs panel, one vs two sessions) |
| `agenda.md` | The run of show as promised in the application and listing |
| `run-sheet.md` | Minute-by-minute day-of plan with owners (fill once venue is known) |
| `follow-up.md` | What attendees get afterwards and what we commit to in the application |

Promotion copy is in `outreach/copy/`, not here. Speaker material is in `speakers/`.
