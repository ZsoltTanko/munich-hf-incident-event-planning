# Zsolt's feedback on application draft v0.2 (S18)

## Original

All right I'm providing feedback on the application draft. We should make it somewhat clear that the organizing team is involved in organizing EA Munich as well as ACX Munich. The signal there is that BlueDot and EA are very closely aligned and we want it to be clear that we are EA people. This also gives us more credibility since we're already organizers for citywide events.

The emphasis is wrong as it is: we're inviting people via our own networks rather than cold promotion. Correct me if I'm wrong but it seems like the BlueDot grant's purpose is to get the message out about recent AI safety events to the general public. The idea that we are hosting an event for our own professional networks is a little bit off from what they're looking for.

I think it's useful for us to signal that we have relevant professional networks that we can leverage but we shouldn't say "rather than cold promotion." That seems like going too far. I'm not sure anyone knows what Bits and Pretzels is. The people who are going to be reading this application won't be aware of Munich-specific events.

Oh yes, we don't have to keep this document in PDF and DOCX form. This can just live as a Markdown file.
