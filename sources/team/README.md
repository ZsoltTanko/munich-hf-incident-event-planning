# sources/team/

Verbatim copies of what the team sends in: chat threads, emails, call transcripts, documents
team members wrote, and files (in `attachments/`). One file per source,
`YYYY-MM-DD-<type>-<slug>.md`, each with a source ID from `sources/INDEX.md` and an
`## Extracted` table showing where its contents went. Created and maintained by the ingest
workflow in `workflows/ingest-source.md`.

Phone numbers and personal email addresses of people outside the team are redacted on the way
in. Nothing here is edited after filing except to add the Extracted table or a "superseded by"
line.
